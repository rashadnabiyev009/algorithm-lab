Algorithm complexity & methodology

BFS

Breadth-first search explores in layers. Time O(V+E), space O(V). Optimal for unweighted graphs.

DFS

Depth-first search follows a branch before backtracking. Time O(V+E), space O(V). Not necessarily optimal.

A*

A* uses f(n)=g(n)+h(n) with Manhattan distance. Its worst-case time and space can grow exponentially with solution depth; performance depends on the heuristic and implementation.

The maze is a grid graph. Each walkable cell is a vertex and orthogonal moves are edges of cost 1. All algorithms receive the same maze; measurements are approximate and not a controlled benchmark. This implementation uses an array-backed priority queue for A* and an array queue for BFS.
